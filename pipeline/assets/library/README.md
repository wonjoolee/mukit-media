# MUKIT 사진 모음 (운영자 촬영 + 공공누리 + 자유 이용 허락)

- 파일 이름: `<주제영문>_<YYYYMMDD>_<번호>.jpg` (예: `studio-monitors_20261110_01.jpg`, `sejong-hall_201905_2475705.jpg`)
- 모든 사진은 `index.csv`에 한 줄씩 기록: file, 주제, 장소, 날짜, 내용, 출처, 이용조건
  - 운영자 사진: 출처 `운영자`, 이용조건 `자유(자르기·글자 얹기 가능)`. 매장·현장·장비·공연장 등.
  - 공공누리 제1유형(한국관광공사 등): 출처 `한국관광공사 촬영자(원문 URL)`, 이용조건 `공공누리 제1유형(출처표시)` — 원본 비율, `PHOTO · 한국관광공사`
  - Wikimedia Commons(CC0·PD·CC BY·CC BY-SA만): 출처 `작가 / 라이선스 · Wikimedia Commons (원문 URL)` — `pipeline/commons.py`로 받으면 .json에 자동 기록
- 긴 변 2000px 이하 JPG로 줄여 저장한다.
- 같은 사진은 7일 안에 다시 쓰지 않는다. 사진 내용과 기사 내용이 다르면 쓰지 않는다.
